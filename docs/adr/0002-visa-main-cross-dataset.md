# 主跨数据集用 VisA，MVTec AD 2 只做公开集压力测试

高分档需要一个跨数据集。主表用 VisA：AnomalyDINO 的原文和官方代码都在同一套 1/2/4/8-shot 协议上报告了 VisA，标注公开，本地可以算完。MVTec AD 2 的正式分数在私有划分上，要交给评测服务器；公开集 TESTpub 只适合试探，图像边长也远大于 MVTec，无法共用同一分辨率。TESTpub 留到背景抑制和多尺度在 MVTec 上跑通之后，用来看光照、透明、重叠和小缺陷，不提交私有榜。

## Considered Options

- VisA 做主跨数据集，AD 2 公开集做后续压力测试（采用）
- AD 2 做主跨数据集：正式测试集没有本地标注，也无法和 AnomalyDINO 的已发表数字对照
- 两个数据集都进主表：协议和分辨率对不齐，6–8 页报告里会挤掉消融
