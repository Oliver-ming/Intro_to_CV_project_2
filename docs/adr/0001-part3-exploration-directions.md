# Part 3 做背景抑制、多尺度特征和提示-视觉融合

作业只要求至少一个改进。我们做三条：背景抑制、多尺度特征、提示与视觉距离融合。它们分别对准背景和光照误报、粗 patch 漏掉的细缺陷，以及把 AnomalyDINO 与 AnomalyCLIP 接到同一次判定上。合成缺陷、记忆库压缩和拒识先不做，避免另开训练目标，或把贡献收成速度和拒识策略。

## Considered Options

- 背景抑制、多尺度特征、提示与视觉距离融合（采用）
- 合成缺陷：要另训打分头，和冻结主干的设定不一致
- 记忆库压缩：主要换速度和显存，不直接回答漏检和误报
- 选择性预测：改的是拒识，不提高定位本身
