# MVTec 的正常图按固定种子划出阈值验证图

MVTec AD 的官方划分没有单独的正常验证集。若用测试集里的正常图定工作点，就用到了测试划分。每个类别从 `train/good` 里按种子 0 抽出 10 张作为阈值验证图，其余进入参考池。清单写成 `outputs/splits/mvtec/<category>.json`，所有方法共用。Part 1 使用整份参考池。Part 2 的 1/2/4/8-shot 只从参考池抽取，不碰阈值验证图。

## Considered Options

- 每类 10 张、种子 0、方法间共用清单（采用）
- 用 `test/good` 定阈值：这些图属于官方测试划分
- 每个方法各自随机划分：工作点不再可比
