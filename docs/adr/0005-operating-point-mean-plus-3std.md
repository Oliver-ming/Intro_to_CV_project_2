# 工作点取阈值验证图分数的均值加 3 倍标准差

作业禁止用测试标签选阈值。自采检验集只有 10 张阈值验证图，一张图就是 10% 的误报率，表达不了 1% 这种目标。图像异常分数取热力图的最大像素值。每个方法、每个类别各自在自己的阈值验证图上计算均值加 3 倍标准差，标准差除以样本数 n。跨方法不共用一个数值。图像判定和二值热力图共用这个分界。测试集上的实际误报率照实报告。

## Considered Options

- 均值加 3 倍标准差，按方法、按类别分别计算（采用）
- 验证图最大分数：10 张里的一张异常偏高就会把工作点抬到检不出缺陷
- 在测试集上按 F1 或目标误报率选阈值：作业明确禁止
